# 7.3 Networks

This is a major part of Core Area 7.

Students should be confident applying network knowledge to scenarios.

## Benefits and Drawbacks of Networks

Possible benefits include:

- resource sharing
- data sharing
- communication

Possible drawbacks include:

- administration requirements
- infrastructure requirements

## Wired

---

# Network Topologies

Students should understand:

## Star

Devices connect through a central point.

## Mesh

Nodes may have multiple connections, providing alternative routes.

## Tree

Uses a hierarchical structure containing connected branches.

Students should also understand the distinction between:

- physical topology
- logical topology

A **physical topology** describes the physical connection of devices.

A **logical topology** describes how data moves through the network.

---

# Network Models

Students should understand:

## Client-Server

Clients request resources or services from servers.

## Thin Client

A client relies heavily on central server resources.

## Peer-to-Peer

Devices share resources directly rather than relying entirely on a dedicated central server.

Students should be able to consider benefits and drawbacks in context.

---

# Network Components

Students should understand the role of:

- server
- client
- router
- network switch
- internet connection
- internet backbone

A **router** forwards traffic between networks.

A **switch** connects devices and forwards traffic within a network.

These roles should not be confused.

---

# OSI Model

Students should understand the seven layers:

1. Application
2. Presentation
3. Session
4. Transport
5. Network
6. Data Link
7. Physical

Students should understand the **function and related protocols** of each layer.

---

# TCP/IP Model

Students should understand the four layers:

1. Application
2. Transport
3. Internet
4. Network

Students should understand the functions and related protocols of these layers.

---

# Data Packets

Students should understand:

- contents and structure of packets
- role of packet components
- packet switching
- causes of packet loss
- error handling
- cyclic redundancy check (CRC)

Packet switching allows data to be divided into packets for transmission through a network.

CRC can be used to detect errors in transmitted data.

# Bandwidth and Latency

## Bandwidth

The capacity available for transferring data across a connection.

## Latency

The delay involved in network communication.

Students should understand how both can affect the performance of networks and connected systems.

Important misconception:

**High bandwidth does not automatically mean low latency.**

### Type 1
Operates directly on host hardware.

### Type 2

---

# Virtual Environment Features

Students should understand:

- increased security
- managed execution
- sharing
- aggregation
- emulation
- isolation
- portability

---

# Benefits of Virtual Environments

Students should understand:

- cost effectiveness for large environments
- easy management
- resilience
- potentially lower carbon footprint
- improved disaster recovery
- improved testing environments
- education and training opportunities

---

# Drawbacks of Virtual Environments

Students should understand:

- extra hardware load
- slower execution time
- possible false representation of performance

Students should not automatically assume virtualisation is always the best option.

Suitability depends on the scenario.
